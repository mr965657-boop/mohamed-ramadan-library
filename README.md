# منصة مكتبة محمد رمضان المعرفية الرقمية
### Mohamed Ramadan Digital Library

منصة معرفية رقمية متكاملة تجمع بين أصالة التراث الإسلامي والتصميم الرقمي المعاصر، مبنية وفق أحدث المعايير البرمجية والأمنية لتوفير بيئة قراءة وبحث رصينة.

---

## 🌟 الميزات المنجزة في المشروع

1. **الواجهة الأمامية والهوية البصرية:**
   - مبنية باستخدام **Astro 5 + React + Tailwind CSS**.
   - دعم كامل ثنائي اللغة (**العربية RTL** والإنجليزية LTR).
   - لوحة ألوان مستلهمة من العمارة الإسلامية والتراث (العاجي، الأخضر الزمردي `#143D33`، الأزرق التراثي `#1B365D`، والذهبي الهادئ `#B8924A`).
   - خطوط عربية أصيلة: *Amiri*، *Noto Naskh Arabic*، و*Aref Ruqaa*.

2. **الأقسام المعرفية الستة:**
   - **الكتب والمؤلفات:** فهرس مع أغلفة الكتب، النبذات، وعدد الصفحات، وزر القراءة المباشرة والتنزيل.
   - **البحوث والدراسات:** قراءة أكاديمية متكاملة تدعم التوثيق والمراجع وخلاصة البحث وخيار الطباعة.
   - **المقالات الفكرية:** واجهة قراءة مريحة مع أدوات تحكم بحجم الخط (A+ / A-) وتقدير وقت القراءة.
   - **المحاضرات والدروس:** مشغل صوتيات MP3 مدمج مع تفريغ نصي للمحاضرة وإمكانية التحميل.
   - **الأعمال الأدبية:** نصوص وسرديات إبداعية.
   - **المواد التعليمية:** حقائب تدريبية ومناهج دراسية.
   - **صفحة عن المؤلف:** سيرة ذاتية ومؤلفات واهتمامات بحثية.
   - **صفحة تواصل:** نموذج متكامل يفرز الرسائل حسب التصنيف ويرسلها مباشرة إلى لوحة الإدارة.

3. **قارئ الـ PDF التفاعلي (PDF.js + Flipbook):**
   - قراءة الكتب والمخطوطات مباشرة داخل المتصفح بجودة عالية دون إجبار الزائر على التنزيل.
   - أدوات تكبير وتصغير (Zoom In / Zoom Out)، والتنقل بين الصفحات بالأزرار ومفاتيح الأسهم.
   - وضع تقليب الصفحات (Flipbook Mode).
   - **حفظ موضع القراءة تلقائياً:** يتذكر المتصفح رقم الصفحة التي توقفت عندها ويستأنفها في زيارتك القادمة.

4. **محرك البحث الذكي (Arabic Full-Text Normalizer):**
   - محرك بحث متقدم يطابق الكلمات مع تطبيع الهمزات (أ، إ، آ)، وتطبيع الياء والألف المقصورة، وإزالة التشكيل والكشيدة.
   - تصفية النتائج حسب الأقسام (كتب، بحوث، مقالات، محاضرات).

5. **لوحة التحكم الإدارية الكاملة (Admin Dashboard):**
   - مسار `/admin` مصمم بالكامل باللغة العربية (RTL).
   - إحصائيات فورية للمصنفات والرسائل والمشتركين.
   - إدارة المحتوى (CRUD): إضافة عمل جديد، تعديل، حذف، وتغيير الحالة (منشور/مسودة).
   - محرر نصوص غني مع أدوات تنسيق العناوين والاقتباسات.
   - صندوق رسائل التواصل مع إمكانية الرد المباشر عبر البريد الإلكتروني وأرشفة الرسائل.
   - إدارة الأدوار والصلاحيات (RBAC: Super Admin, Editor, Author, Translator, Media Manager).

6. **تطبيق الويب التقدمي (PWA) و SEO:**
   - ملف `manifest.json` وأيقونات التثبيت على الهاتف كـ تطبيق مستقل.
   - `sw.js` (Service Worker) لتخزين الصفحات وإتاحة القراءة دون اتصال.
   - خريطة موقع ديناميكية `/sitemap.xml` و `robots.txt` وبيانات وصفية (OpenGraph & Twitter Cards).

## 🛠️ البنية التقنية (Tech Stack)

* **الإطار العام:** [Astro](https://astro.build/) (وضع SSR / خادم هجين)
* **المكونات التفاعلية:** [React](https://react.dev/)
* **التنسيق والأنماط:** [Tailwind CSS](https://tailwindcss.com/)
* **محول النشر:** [@astrojs/vercel](https://www.npmjs.com/package/@astrojs/vercel)
* **قاعدة البيانات:** PostgreSQL عبر [Supabase](https://supabase.com/) مع سياسات حماية متقدمة (Row Level Security - RLS)
* **قارئ الكتب:** [PDF.js](https://mozilla.github.io/pdf.js/)
* **الأيقونات:** Lucide Icons

## 🚀 طريقة التثبيت والتشغيل المحلي

### 1. المتطلبات الأساسية
* Node.js (الإصدار 18 فما فوق، تم التثبيت على v26.13.1)
* Git

### 2. التثبيت
```bash
# تثبيت الحزم والمكتبات
npm install
```

### 3. إعداد متغيرات البيئة
انسخ ملف الإعداد النموذجي:
```bash
cp .env.example .env
```
وقم بملء مفاتيح Supabase إذا رغبت بالربط السحابي المباشر. (المنصة مجهزة للعمل تلقائياً في وضع التطوير المحلي بدون إعداد مسبق).

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:4321`

### 5. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
```

## 🗄️ إعداد قاعدة البيانات (Database & Migrations)

ملفات الـ SQL موجودة في مجلد `supabase/migrations/`:
1. `20261124000000_initial_schema.sql`: الجداول الأساسية (items, categories, profiles, messages, subscribers, reading_progress) وسياسات الـ RLS.
2. `20261124000001_arabic_search_helpers.sql`: دوال ومحفزات تطبيع وبحث اللغة العربية الفائقة.
3. `supabase/seed.sql`: البيانات المعيارية الأولية والتصنيفات الافتراضية.

لتطبيقها في Supabase:
انسخ محتوى الملفات وضعه في **SQL Editor** داخل لوحة تحكم مشروعك في Supabase واضغط **Run**.

## ☁️ النشر على Vercel

المشروع مهيأ تماماً للنشر المباشر على Vercel:
1. ارفع المشروع إلى مستودع GitHub الخاص بك:
   ```bash
   git add .
   git commit -m "Initial release of Mohamed Ramadan Digital Library"
   git branch -M main
   git remote add origin <your-repo-url>
   git push -u origin main
   ```
2. ادخل إلى [Vercel](https://vercel.com)، واختر المستودع.
3. أضف متغيرات البيئة من ملف `.env.example` في إعدادات **Environment Variables**.
4. اضغط **Deploy**.
